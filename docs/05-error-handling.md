# 05. 오류 처리 지침 (F8, F9)

> 오류가 났을 때 사용자가 **"무엇이 잘못됐고, 뭘 하면 되는지"** 바로 알 수 있게 하는 것이 목표입니다.
> 모든 문구는 `public/js/messages.js` 한 곳에 모아 둡니다. 서버(`lib/analyze-core.js`)의 `message`도 이 표와 **같은 문구**를 씁니다.

---

## 1. 오류 표시 방법

- 위치: 입력 카드 안 `messageBox` (docs/02 §5.6)
- 형식: **제목**(굵게) + 줄바꿈 + 설명
- 종류: `error`(빨강) / `warning`(노랑)
- 새 메시지가 오면 이전 메시지를 덮어쓴다 (여러 개 쌓지 않음)
- 사용자가 입력창에 글을 고치거나 "처음부터"를 누르면 숨긴다
- `role="alert"`이므로 화면 읽기 프로그램이 자동으로 읽어준다
- **기술 용어(500, fetch, JSON, API 등)를 사용자 문구에 쓰지 않는다.**

## 2. 오류 코드 전체 목록

### 2.1 입력 오류 (브라우저와 서버 모두 검사)

| 코드 | 종류 | 제목 | 설명 | 대체 동작 |
|---|---|---|---|---|
| `EMPTY_INPUT` | error | 내용을 입력해 주세요 | 돌림판에 넣을 항목을 문장으로 적어 주세요. | 없음 |
| `TEXT_TOO_LONG` | error | 글이 너무 길어요 | 500자 이내로 입력해 주세요. | 없음 |
| `INVALID_INPUT` | error | 입력을 읽을 수 없어요 | 내용을 다시 입력한 뒤 시도해 주세요. | 없음 |
| `NOT_ENOUGH_ITEMS` | error | 항목을 2개 이상 찾지 못했어요 | 쉼표(,)로 구분해서 2개 이상 적어 주세요. 예: 짜장, 짬뽕, 볶음밥 | 없음 |

### 2.2 AI·서버 오류

| 코드 | 종류 | 제목 | 설명 | 대체 동작 |
|---|---|---|---|---|
| `SERVER_CONFIG` | warning | AI 분석을 사용할 수 없어요 | 서버 설정에 문제가 있어 쉼표·줄바꿈 기준으로 직접 나눴어요. | **있음** |
| `AI_TIMEOUT` | warning | AI 응답이 늦어요 | 대신 쉼표·줄바꿈 기준으로 직접 나눴어요. | **있음** |
| `AI_RATE_LIMIT` | warning | 지금은 AI 사용량이 많아요 | 대신 쉼표·줄바꿈 기준으로 직접 나눴어요. 잠시 후 다시 시도해 보세요. | **있음** |
| `AI_ERROR` | warning | AI 분석에 실패했어요 | 대신 쉼표·줄바꿈 기준으로 직접 나눴어요. | **있음** |
| `AI_REFUSED` | warning | AI가 이 내용을 분석하지 않았어요 | 대신 쉼표·줄바꿈 기준으로 직접 나눴어요. | **있음** |
| `AI_BAD_OUTPUT` | warning | AI 결과를 읽지 못했어요 | 대신 쉼표·줄바꿈 기준으로 직접 나눴어요. | **있음** |
| `INTERNAL_ERROR` | warning | 서버에 문제가 생겼어요 | 대신 쉼표·줄바꿈 기준으로 직접 나눴어요. | **있음** |
| `METHOD_NOT_ALLOWED` | error | 잘못된 요청이에요 | 페이지를 새로고침한 뒤 다시 시도해 주세요. | 없음 |

### 2.3 네트워크 오류 (브라우저에서만 발생)

| 코드 | 종류 | 제목 | 설명 | 대체 동작 |
|---|---|---|---|---|
| `NETWORK_ERROR` | warning | 인터넷 연결을 확인해 주세요 | 서버에 연결하지 못해 쉼표·줄바꿈 기준으로 직접 나눴어요. | **있음** |
| `NETWORK_TIMEOUT` | warning | 응답이 너무 늦어요 | 대신 쉼표·줄바꿈 기준으로 직접 나눴어요. | **있음** |
| `BAD_RESPONSE` | warning | 서버 응답을 읽지 못했어요 | 대신 쉼표·줄바꿈 기준으로 직접 나눴어요. | **있음** |

### 2.4 안내 (오류는 아님)

| 코드 | 종류 | 제목 | 설명 |
|---|---|---|---|
| `LOW_CONFIDENCE` | warning | 분석 결과가 정확하지 않을 수 있어요 | 항목이 맞는지 확인해 주세요. 다르면 쉼표로 구분해 다시 입력해 보세요. |
| `FALLBACK_FAILED` | error | 항목을 나누지 못했어요 | AI를 사용할 수 없고, 직접 나누기도 실패했어요. 쉼표(,)로 구분해서 2개 이상 적어 주세요. |

### 2.5 알 수 없는 코드
서버가 위 표에 없는 코드를 보내면 `AI_ERROR`와 같이 처리한다.

## 3. `messages.js` 형식

```js
// 화면에 보여줄 오류·안내 문구 모음
export const MESSAGES = {
  EMPTY_INPUT: { type: 'error', title: '내용을 입력해 주세요', body: '돌림판에 넣을 항목을 문장으로 적어 주세요.', fallback: false },
  // ... 2장의 모든 코드
};

export function getMessage(code) {
  return MESSAGES[code] || MESSAGES.AI_ERROR;
}
```

## 4. 대체 동작: 직접 나누기 (F9)

AI를 쓸 수 없을 때(표에서 대체 동작 "있음")도 사용자가 돌림판을 쓸 수 있게 합니다.

### 4.1 `parser.js`의 `splitLocally(text)` 규칙

| 순서 | 처리 |
|---|---|
| 1 | 구분자로 나눔: 쉼표 `,` `，`, 줄바꿈, 가운뎃점 `·`, 슬래시 `/`, 세로선 `\|`, 그리고 앞뒤 공백이 있는 `vs` / `VS` → 정규식 `/[,，\n·\/|]+|\s+vs\s+/i` |
| 2 | 각 조각 `trim()`, 연속 공백 1칸으로 |
| 3 | 빈 조각 제거 |
| 4 | 20자 초과 조각은 앞 20자만 (`Array.from` 사용) |
| 5 | 중복 제거 (대소문자 무시, 처음 것 유지) |
| 6 | 앞 12개만 |
| 7 | 2개 미만이면 `null` 반환 (실패) |

- 반환: 성공 시 `string[]`, 실패 시 `null`
- 예: `짜장, 짬뽕\n볶음밥` → `['짜장', '짬뽕', '볶음밥']`
- 예: `민트초코 vs 반민초` → `['민트초코', '반민초']`
- 예: `오늘 뭐 먹지` → `null`

### 4.2 대체 동작 흐름

```
서버 응답이 실패 + 해당 코드의 fallback이 true
   ↓
splitLocally(text)
   ├─ 성공 → app.source = 'fallback', confidence = null
   │         reason = 'AI 분석을 사용할 수 없어 쉼표·줄바꿈 기준으로 나눴어요.'
   │         분석 카드: 신뢰도 '—', 배지 'AI 미사용', 막대 숨김
   │         돌림판 그리기 → 상태 ready
   │         messageBox에 원래 오류 코드의 warning 표시
   └─ 실패 → 상태 error, messageBox에 FALLBACK_FAILED (error)
```

## 5. 개발자용 로그 규칙

| 위치 | 남길 것 | 남기지 말 것 |
|---|---|---|
| 서버 (`console.error`) | `[analyze]` 접두사, 오류 코드, OpenAI HTTP 상태, 짧은 원인 | API 키, 사용자 입력 전문, OpenAI 응답 전문 |
| 브라우저 (`console.warn`) | `[api]` 접두사, 오류 코드 | 정상 동작 중 불필요한 로그 (`console.log` 남기지 않기) |

---

## 6. 완료 기준

- [ ] 2장의 모든 코드가 `messages.js`에 있고, 문구가 표와 글자 하나까지 같다.
- [ ] 서버 응답의 `message`와 `messages.js` 문구가 같다.
- [ ] 대체 동작 "있음" 코드에서 쉼표 입력이면 돌림판이 만들어진다.
- [ ] 사용자에게 보이는 문구에 기술 용어가 없다.

## 7. 검증 방법

| 상황 | 재현 방법 | 기대 화면 |
|---|---|---|
| 빈 입력 | 공백만 넣고 만들기 | 빨간 박스 "내용을 입력해 주세요", 입력창 빨간 테두리 |
| 500자 초과 | 501자 붙여넣기 | 빨간 박스 "글이 너무 길어요", 글자 수 빨간색 |
| 항목 부족 | `안녕하세요` 입력 | 빨간 박스 "항목을 2개 이상 찾지 못했어요" |
| 키 없음 | `.env` 키 삭제 후 재시작, `a, b, c` 입력 | 노란 박스 "AI 분석을 사용할 수 없어요" + 3칸 돌림판, 신뢰도 '—' |
| 키 없음 + 나눌 수 없음 | 위 상태에서 `오늘 뭐 먹지` 입력 | 빨간 박스 "항목을 나누지 못했어요" |
| 오프라인 | 개발자도구 Network → Offline, `a, b` 입력 | 노란 박스 "인터넷 연결을 확인해 주세요" + 2칸 돌림판 |
| 낮은 신뢰도 | 애매한 입력 (예: `우리 팀에서 오늘 야근할 사람 정하기`) | 신뢰도 50 미만이면 노란 박스 "정확하지 않을 수 있어요" |
| 다시 입력 | 오류 후 입력창에 글자 입력 | 메시지 박스 사라짐 |
